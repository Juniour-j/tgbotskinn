# lis-price-bot

Telegram-бот: кидаєш назву скіна й цільову ціну — отримуєш сповіщення, коли
найдешевший лот цього скіна на **lis-skins.com** падає до неї або нижче.

Працює на безкоштовних експортах lis-skins — **API-ключ не потрібен**:

- `csgo.json` (~4 МБ, раз на 60 с) — каталог назв;
- `api_csgo_full.json` (~160 МБ gzip, раз на `DEPTH_REFRESH_MIN`) — **точна ціна**
  й глибина ринку. Тягнеться, лише коли є хоч одне стеження.

**Ціна = як на сайті.** Береться з повного експорту, з нього відкидаються поодинокі
щойно виставлені лоти на самому дні (сайт їх теж ще не показує). Точний розклад —
`/depth`. Короткий `csgo.json` для цін не використовується (він занижений на кейсах).

## Ринки

Звичайне стеження за ціною порівнює **кілька ринків** і алертить, коли **будь-де**
ціна впаде нижче цілі:

| Ринок | Джерело | Дані |
|---|---|---|
| lis-skins | `market_export_json` | ціна + **глибина** (для `x<шт>`) |
| market.csgo.com | `api/v2/prices/USD.json` | ціна + обсяг |
| Skinport | `api.skinport.com/v1/items` | ціна + обсяг |

Увімкнені ринки — env `SOURCES` (напр. `mcsgo,skinport`; пусто = лише lis-skins).
Глибина (`x<шт>`, `/depth`) працює **тільки на lis-skins** — лише він дає полистинговий фід.
`/compare <назва>` — ціни на всіх ринках без стеження.

## Користування

Все через кнопки. Нижня клавіатура: **➕ Додати · 📋 Список · 🔎 Пошук · ❓ Довідка**.
Під `/list` — `📊` глибина · `🔀` порівняти · `🔕` мут · `🗑`.

**Додати:** написати одним рядком `<назва> <ціна>` або `<назва> <ціна> x<шт>`
(напр. `Kilowatt Case 0.13 x200`). Не знаєш точну назву — написати частину →
бот покаже варіанти кнопками → тапнути → надіслати ціну.

**Список** — під кожним стеженням кнопки `📊` (глибина) · `🔕/🔔` (мут) · `🗑` (видалити).

Команди теж працюють: `/watch /depth <id> /find /list /unwatch <id> /mute <id> /unmute <id> /menu /whoami`.

`x<шт>` — сповіщення, коли можна **купити** `>= шт` лотів по `<= ціна`
(рахується як «Filters match» у Bulk Buy на сайті).

Ціни в **доларах**. Сповіщення приходить один раз; знову спрацює, лише якщо умова
знову перестане й почне виконуватись (re-arm).

### Навіщо `x<шт>`

Для оптової закупки важлива не мінімальна ціна (там часто висить пара лотів), а
**скільки лотів є по прийнятній ціні** та **за скільки набрати потрібну кількість**.
`x<шт>` дає сповіщення, коли по `<= ціна` набереться `>= шт` лотів, і показує
`N шт від $X` — найдешевшу ціну, за якою набирається саме твоя кількість.

Бот **багатокористувацький**: кожен, хто напише боту, має власний ізольований
список стежень і отримує лише свої сповіщення. Щоб пустити тільки певних людей —
задай `ALLOWED_USER_IDS` (їхні id через кому; свій дізнатись командою `/whoami`).
Порожнє значення — доступ відкритий усім.

## Обмеження

- Ціна й глибина відстають до `DEPTH_REFRESH_MIN` хвилин (файл великий).
- Watch на конкретний float / стікери неможливий (для цього потрібен платний API).
- Поки глибина для назви ще не завантажилась (перші ~1 хв після `/watch`) —
  показується орієнтовна ціна з `csgo.json`, позначена `(~)` / `(орієнтовно)`.

## Локальний запуск (Windows / PowerShell)

```powershell
cd "F:\Новая папка (2)\lis-price-bot"
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env      # вписати TELEGRAM_TOKEN, зберегти
.\.venv\Scripts\python.exe -m bot
```

`.env` — єдине місце для токена локально (у git не потрапляє, він у `.gitignore`):

```
TELEGRAM_TOKEN=8944xxxxxxx:AAF...новий_токен_від_BotFather
DB_PATH=bot.db
```

Без квадратних лапок і пробілів навколо `=`. Зупинка бота — `Ctrl+C`.

Тести:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
```

## Деплой на Railway

1. Запуш репо в GitHub, у Railway → **New Project → Deploy from GitHub**.
2. Railway (Nixpacks) сам підхопить Python з `requirements.txt` і команду з `Procfile`
   (`worker: python -m bot`). Dockerfile не потрібен. HTTP-порт не потрібен.
3. **Variables:**
   - `TELEGRAM_TOKEN` — новий токен від @BotFather
   - `DB_PATH` — `/data/bot.db`
   - (опційно) `POLL_INTERVAL`, `LIS_EXPORT_URL`
4. **Volume:** додай Volume і примонтуй у `/data`. Без нього SQLite-файл
   зітреться на кожному редеплої (ФС Railway ефемерна).
5. Бот працює на long polling — жоден вебхук/домен налаштовувати не треба.

> Always-on воркер потребує платного плану Railway (Hobby, ~$5/міс);
> на free trial вичерпаються години.
